# 文件工具箱 · 本地工具

> **在线版**：<https://a377.xyz> —— 手机浏览器直接打开就能用，不需要装任何东西。
> 纯浏览器实现（pdf.js + pdf-lib + 自己写的 AES），五个功能都有。
> 唯一的差别是受浏览器内存限制，超大文件（几百页 / 600 DPI）容易卡——那种还是用本地版稳。

一个跑在本机的小工具，五个功能装在一起：

| 功能 | 干什么 |
| --- | --- |
| **PDF 转图片** | 每页导出成 PNG / JPG，可选清晰度和页码范围 |
| **重排页面** | 拖缩略图调整页序，导出新的 PDF |
| **合并 PDF** | 多个 PDF 按你排的顺序拼成一个 |
| **拆分 PDF** | 按页码范围拆成多份 |
| **ncm 转音频** | 网易云音乐的 `.ncm` 还原成 mp3 / flac，带歌名、歌手、专辑和封面 |

**全部在本机处理，文件不上传任何服务器。** 服务只监听 `127.0.0.1`，不对局域网或外网开放。

---

## 怎么用

### 最省事：双击桌面上的快捷方式

桌面上有 **「PDF 转图片」** 快捷方式，双击就弹出界面。

> 快捷方式指向本目录的 `启动工具.bat`。工具目录挪了位置的话，双击目录里的
> **`重建桌面快捷方式.bat`** 重新建一个。
> 已经在运行时再双击一次不会起第二个服务，会直接把界面调出来。

### 或者：直接双击 `启动工具.bat`

浏览器会自动打开界面。**用完了直接关掉那个黑窗口**，服务就停了。

### 完全不想开界面？

把 PDF 拖到 **`拖拽转换.bat`** 的图标上，直接在原目录出图（默认 200 DPI、PNG）。

## 各功能怎么用

### PDF 转图片

拖入 PDF，选清晰度、格式、页面范围，点开始。

- **只转 1 页** → 直接给你一张图片文件，不用解压
- **多页** → 每张都列出缩略图，点哪张下哪张；也可以「全部下载」或「打包成 ZIP」

| 选项 | 说明 |
| --- | --- |
| 清晰度 | 72 / 150 / **200（默认）** / 300 / 600 DPI |
| 图片格式 | PNG（无损，适合文字图表）/ JPG（体积小，适合照片） |
| 页面范围 | 留空 = 全部；支持 `1-3`、`1-3,7,12-`，页码从 1 开始 |

### 重排页面

拖入 PDF，等缩略图出来，**直接拖动缩略图**调整顺序。

- 左上角数字是**调整后的位置**，卡片下面写的是**原来第几页**
- 顶部的「当前页序」可以直接手改，比如填 `3,1,2` 或 `5-3`
- **允许重复页**：填 `1,1,2` 会导出两遍第 1 页
- 「反向」「重置」是一键操作
- 原文件不会被改动，导出的是新 PDF

### 合并 PDF

把要合并的 PDF 一次全拖进来，用 **▲▼** 调整先后顺序（第 1 个的页面排在最前面），点合并。

顺序可以在文件列表里上下调，列表里显示的就是最终页序。

### 拆分 PDF

拖入一个 PDF，填拆分规则：

| 填什么 | 结果 |
| --- | --- |
| 留空 | 每页一个 PDF，打包成 ZIP |
| `1-3;4-6;7-` | 拆成三份：1-3 页、4-6 页、7 页到末尾 |
| `2-4` | 只拆出一份，直接给一个 PDF 而不是 ZIP |

分号是「分成几份」的分隔符，逗号和横线在每一份内部用。

### ncm 转音频

把 `.ncm` 拖进来，转出来的就是能直接播放的 mp3 或 flac。

- 文件名叫 **`歌手 - 歌名.mp3`**，不再是乱码
- 歌名、歌手、专辑会写进音频标签，**专辑封面也会嵌进去**
- 格式是 mp3 还是 flac 由音频数据本身判断，不看文件名
- 不想要标签？把「写入歌曲信息」改成「不写入」

> 仅供备份你自己已经下载或购买的音乐，别拿去传播受版权保护的内容。

## 实测性能

| 场景 | 结果 |
| --- | --- |
| 5 页 A4 转图片 @150 DPI | 0.18 秒 |
| 50 页 A4 转图片 @200 DPI | 3.0 秒，输出 1.2 MB |
| 单页 A4 @600 DPI | 0.49 秒，4959×7017 px |
| ncm 解密 3 秒的 mp3 | 毫秒级（密钥流按 256 周期用大整数异或） |

## 常见情况

**提示「还没连上本地服务」**
页面没等到后端。先双击 `启动工具.bat`，等黑窗口出现后再刷新页面。

**首次启动慢**
第一次会检查并安装组件（PyMuPDF、pycryptodome、mutagen），之后启动是秒开。

**提示「这个 PDF 有密码保护」**
加密 PDF 暂不支持，先用别的工具去掉密码。

**提示「超出安全上限」**
DPI 设太高。A4 在 1200 DPI 下是 1.39 亿像素、几百 MB 内存，工具会提前拦下来。降到 600 以内。

**合并时提示「至少要 2 个 PDF」**
合并本来就是多合一，只给一个文件没意义。

**ncm 提示「文件头不是 CTENFDAM」**
这不是 ncm 文件，或者文件下载不完整（网易云有时会留下半截文件）。

**转出来的歌没有封面**
网易云 3.0 之后的某些版本下载的 ncm 本身就不带封面，工具只能还原文件里有的东西。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `启动工具.bat` | 启动网页界面（主入口） |
| `拖拽转换.bat` | 拖 PDF 上去直接转图片 |
| `重建桌面快捷方式.bat` | 快捷方式丢了或目录挪了之后重建 |
| `app.py` | 后端：本地 HTTP 服务 + 路由 |
| `pdfops.py` | PDF 页面操作：重排、合并、拆分、缩略图 |
| `ncm.py` | ncm 解密 + 写音频标签 |
| `index.html` | 前端界面（完全离线，零外部资源） |
| `cli.py` | 命令行 / 拖拽模式的入口 |
| `make_shortcut.py` | 建桌面快捷方式的脚本 |
| `icon.ico` | 快捷方式图标（7 个尺寸） |
| `_find_python.bat` | 探测可用 Python，几个 bat 共用 |

> 几个 bat 都是 **GBK 编码且不切换代码页**。别用编辑器把它另存成 UTF-8，否则 cmd
> 按字节偏移读行会错位，报出 `'PYEXE' 不是内部或外部命令` 这类莫名其妙的错。

## 技术栈

- **PDF 渲染与页面操作**：PyMuPDF（比 pdf2image 少一个 poppler 依赖，装上就能用）
- **ncm 解密**：pycryptodome（AES-ECB）+ 手写 RC4 KSA，算法对照 [taurusxin/ncmdump](https://github.com/taurusxin/ncmdump)
- **音频标签**：mutagen（纯 Python，写 ID3v2 / FLAC 标签和封面）
- **服务**：Python 标准库 `http.server`，无 Web 框架；multipart 用标准库 `email` 解析
- **前端**：原生 JS，单文件，零外部资源

接口说明与已知限制

同步模式：提交 POST /draw/v1/images/generations（不带 async）会阻塞到出图后直接返回 data[].url，通常 15~60 秒。也兼容 Gemini 形状的 candidates[].content.parts[]。

为什么不用异步：带 async: true 时结果要从站点级 GET /v1/tasks/{task_id} 轮询，但该接口没有开放跨域（CORS），浏览器读不到响应，所以纯网页只能用同步模式。页面已保留兜底提示，万一服务端转成异步会告知任务号。
